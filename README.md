# Lezo-AI — نسخة متوافقة مع Vercel

واجهة عربية RTL لـ Lezo-AI مع Backend مبني على Express، وتسجيل حسابات بكلمات مرور مشفّرة، وجلسات HttpOnly، وربط OpenRouter من جهة الخادم.

## ما الذي تم تجهيزه؟
- إضافة `api/[...path].js` لتوجيه طلبات `/api/*` إلى الـ Express backend على Vercel.
- إبقاء الواجهة الحالية وملفاتها دون إعادة بنائها من الصفر.
- حسابات المستخدمين محفوظة في PostgreSQL، وكلمات المرور محفوظة باستخدام bcrypt hash.
- مفتاح OpenRouter وJWT secret يقرآن من Environment Variables على الخادم فقط.
- واجهة `/api/health` لفحص وصول طلبات API.
- أخطاء واضحة إذا كانت متغيرات قاعدة البيانات أو الجلسة غير مضبوطة.

## خطوات النشر على Vercel

### 1) ارفع التعديلات إلى نفس مستودع GitHub
انسخ محتويات هذا المجلد إلى جذر المستودع الحالي `m90890420-web/Lezo-AI`، مع استبدال الملفات التي لها نفس الاسم وإضافة مجلد `api`. لا تنشئ مستودعًا جديدًا. يجب أن يكون `package.json` في جذر المستودع.

### 2) جهّز قاعدة PostgreSQL
تسجيل الحسابات لا يعمل بدون قاعدة PostgreSQL متاحة على الإنترنت. أنشئ قاعدة بيانات لدى مزوّد يدعم PostgreSQL، ثم انسخ رابط الاتصال الخاص بها (`DATABASE_URL`). اختر TLS/SSL إذا طلب مزوّد قاعدة البيانات ذلك. راجع حدود الخطة المجانية وسياسة النوم/الحذف قبل الاختيار؛ المجاني ليس غير محدود.

### 3) أضف Environment Variables في مشروع Vercel
من Settings → Environment Variables أضف هذه القيم، على الأقل لبيئة Production:

| Key | Value |
|---|---|
| `OPENROUTER_API_KEY` | مفتاح OpenRouter الحقيقي، سرّي ولا يوضع في ملفات الواجهة |
| `OPENROUTER_MODEL` | `openrouter/auto` أو معرّف موديل متاح في حسابك |
| `DATABASE_URL` | رابط PostgreSQL الخاص بك |
| `JWT_SECRET` | قيمة عشوائية طويلة وفريدة، 32 بايت أو أكثر |
| `NODE_ENV` | `production` |

لا ترسل الأسرار في المحادثات ولا تحفظها في GitHub. بعد حفظ/تغيير المتغيرات، أعد النشر من Deployments → Redeploy.

### 4) اختبر الـ API
بعد النشر افتح `https://YOUR-DOMAIN/api/health`؛ يفترض أن يظهر JSON مثل `{"ok":true,"service":"Lezo-AI"}`. هذا الاختبار يفحص أن مسار API وصل إلى Backend، ولا يثبت وحده أن قاعدة البيانات أو OpenRouter يعملان.

بعدها جرّب إنشاء حساب جديد من الواجهة. إذا فشل، افتح Vercel → Logs أو Functions Logs وسجّل نص الخطأ فقط دون أي أسرار.

## حدود النسخة الحالية
- المحادثات تُحفظ محليًا في المتصفح، وليست محفوظة بعد في قاعدة البيانات؛ مسح بيانات المتصفح قد يحذفها.
- إرفاق الملفات في الواجهة يعرض أسماء الملفات فقط؛ رفع محتوياتها غير مفعّل.
- لا يوجد استرجاع كلمة مرور بالبريد الإلكتروني.
- استخدام OpenRouter قد يحتاج رصيدًا، ويخضع لحدود حسابك والموديل المختار.
- خطط قواعد البيانات والاستضافة لها حدود استخدام وقد تتغير؛ راجع تسعير المزوّد قبل الاعتماد عليها.

## تشغيل محلي (اختياري)
يتطلب Node.js 20+ وقاعدة PostgreSQL. انسخ `.env.example` إلى `.env` وضع القيم المحلية فيه، ثم:

```bash
npm install
npm start
```

لا ترفع ملف `.env` إلى GitHub.
